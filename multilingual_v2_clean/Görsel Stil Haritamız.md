# Görsel Stil Haritamız

Bu dosya, uygulamada kullanılan görsel stillerin Frontend (TR/EN) isimleri ile Backend tarafında yapay zekaya (Google Vertex AI) gönderilen uzun teknik komutlar arasındaki eşleşmeyi içerir.

| Frontend İsim (TR) | Frontend Name (EN) | Backend Teknik Komut (Long Prompt) |
| :--- | :--- | :--- |
| **Sulu Boya** | Watercolor | `soft watercolor painting style, delicate brushstrokes, vibrant yet dreamy colors, artistic paper texture, fluid edges` |
| **3D Pixar Stili** | 3D Pixar Style | `3D animated feature film style, cinematic volumetric lighting, high-detail textures, big expressive eyes, bright playful colors, masterpiece quality` |
| **Pastel Düşler** | Pastel Dreams | `dreamy pastel colors, soft hazy atmosphere, ethereal lighting, gentle storybook illustration style, whimsical and sweet` |
| **Anime** | Anime | `modern anime art style, crisp lineart, vibrant cel-shading, cinematic anime composition, expressive characters, Studio Ghibli inspired atmosphere` |
| **Yağlı Boya** | Oil Painting | `classic oil painting style, visible thick impasto brushstrokes, rich deep colors, dramatic lighting, canvas texture, museum masterpiece quality` |
| **Pop Art** | Pop Art | `bold pop art style, vibrant saturated colors, thick black outlines, halftone dot patterns, comic book aesthetic, energetic and modern` |
| **Çizgi Film** | Cartoon | `classic high-quality 2D cartoon style, clean vectors, cheerful bright colors, friendly character design, professional animation look` |
| **Vintage Retro** | Vintage Retro | `1970s vintage film aesthetic, faded colors, warm analog grain, soft vignette, nostalgic texture, retro storybook feel` |

**Not:** Veritabanında (özellikle Admin tarafından üretilen taslaklarda) stil alanında bu uzun cümlelerin tamamı görünebilir. "Akıllı Sözlük" mantığı bu verileri temizlemek için bu tabloyu referans almaktadır.
